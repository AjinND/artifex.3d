# Artifex3D operations

Use Node 22 and a MongoDB replica set with transactions. Install from the lockfile with `npm ci`. Supply deployment settings from `.env.example` through your secret manager. Set APP_ORIGIN to the exact public HTTPS origin. The web process runs `npm run build` followed by `npm start`. Run `npm test` after a build for the isolated browser and payment-contract rehearsal.

The supplied sample is stored privately under `studio-assets/balancing-form`. Its HANDOFF.md lists the remaining photos and product details.

## Environment variables

Copy `.env.example` to `.env.local` for shared local settings and fill in the variables for the features you use. Put `npm run dev` overrides, such as localhost paths, in `.env.development.local`. Both files belong at the project root alongside `package.json`. For deployment, inject values through the host's environment or secret manager. Keep credentials and secrets out of source control and `NEXT_PUBLIC_` variables. Artifex3D does not require any `NEXT_PUBLIC_` variables.

Next.js checks these sources in order and uses the first value it finds for each variable:

1. The running process environment.
2. `.env.$(NODE_ENV).local`.
3. `.env.local`, skipped when `NODE_ENV=test`.
4. `.env.$(NODE_ENV)`.
5. `.env`.

Next.js normally sets `NODE_ENV` to `development` for `npm run dev` and `production` for build and start. `NEXT_RUNTIME` and `NEXT_PHASE` are managed by Next.js. The `worker` and `accounts` npm scripts explicitly read `.env.local` with `--env-file` and use any exported values already present in the process. These scripts do not use Next.js file precedence. Restart the web process and worker after changing settings. Rebuild when changing values used by statically rendered pages, such as the public contact address.

`JWT_SECRET` was used by the previous bearer-token implementation. Current authentication uses server-side MongoDB sessions and an HttpOnly cookie. A legacy `JWT_SECRET` entry in a local file is unnecessary for the current app.

For `npm test`, `CHROME_PATH` can override the browser executable. The runner checks the standard Windows Chrome path before using Playwright's Chromium. Set `TEST_LOCAL_UPLOAD_SCANNER` to an absolute Defender executable path to include the real Windows scan test. The runner configures its own temporary MongoDB replica set and isolated payment fixture, including the internal `ARTIFEX_TEST_PROVIDER` flag. `FIXTURE_MONGODB_URI` is only for `scripts/seed-products.ts`, which also requires `NODE_ENV=development` and a listing JSON argument. Use an isolated database for seed data.

## Localhost storage without AWS

Run a local MongoDB replica set and set `MONGODB_URI` to its `mongodb://127.0.0.1` address. For example, if its port is 27017 and its replica set is named `rs0`, use `mongodb://127.0.0.1:27017/artifex3d_dev?replicaSet=rs0`. Set the exact loopback HTTP `APP_ORIGIN` for Next.js. With the project on `E:/Projects/artifex3d`, a sample `.env.development.local` storage section is:

```dotenv
APP_ORIGIN=http://localhost:3000
LOCAL_CATALOG_MEDIA_DIR=E:/Projects/artifex3d/.local/catalog-media
LOCAL_UPLOAD_DIR=E:/Projects/artifex3d/.local/quote-attachments
LOCAL_UPLOAD_SCANNER=
```

Replace both example paths with absolute paths for your project. `.local/` is ignored by Git and the Vercel upload configuration. The catalog directory serves approved public images and previews. Keep quote attachments outside `public/` and separate from the catalog directory. Windows Defender scans attachments before the app makes them available. When Defender cannot be found or its scan fails, the app keeps the attachment unavailable. Set `LOCAL_UPLOAD_SCANNER` if the detected location needs an override. Both local modes use disk and can run without AWS settings. Local quote attachments specifically require Windows; local catalog media also requires a loopback origin and MongoDB on `127.0.0.1`.

## Catalog cutover

Take a database snapshot and restore it to an isolated environment first. Run `npx tsx --env-file=.env.local scripts/migrate-catalog.ts` to inspect existing indexes. If it reports the legacy unique numeric ID index, run with `--apply` during a maintenance window on the restored database first. The partial index preserves numeric IDs and allows new products to use MongoDB IDs. Legacy documents stay unpublished until their approved details are entered. To retain old cart mappings, enter the existing numeric product ID in the new-listing editor when approving a legacy listing. Never infer an INR price from a legacy dollar amount.

Create the intended operator account, configure STAFF_EMAIL and its private base32 authenticator secret in the deployment environment, and enroll the operator's authenticator through a private channel. The initial deployment supports one MFA-enrolled operator. Run `npm run accounts` to list account IDs requiring review. Resolve unexpected administrators and reset accounts with malformed password hashes. Use `npm run accounts -- --provision-staff` for the approved account. Old browser bearer tokens have no authority.

From the staff workspace, enter approved dimensions, finish, INR price, production time and photo descriptions. Order the photos with the cover first. Upload public display assets to the separate catalog media bucket or supply reviewed files in public/catalog (or mount a read-only directory through CATALOG_MEDIA_DIR). Enable rotation only for a self-contained reduced-detail GLB under 10 MB. Preview and publish from the same editor.

## Fulfillment settings

Set SERVICEABLE_PINS to comma-separated six-digit PIN codes. TAX_BASIS_POINTS applies to the catalog subtotal. SHIPPING_PAISE is a flat delivery fee. Activate these values only if the business approves that pricing model. Quote totals include shipping and tax. Publish approved business contacts and policies before enabling live sales.

Configure the Razorpay key pair and independent webhook signing secret. Enable capture, subscribe the HTTPS endpoint /api/payments/webhook to payment.captured, order.paid and refund.processed, and monitor delivery failures. Pending orders can resume from the customer profile. For ambiguous provider creation, reconcile by the local order ID in the provider receipt field before issuing a new attempt. Use provider dashboards for refunds.

## Private files and email

Set AWS_REGION and role-based S3 access. Enable versioning on PRIVATE_UPLOAD_BUCKET and block public access on both buckets. Permit browser PUT from APP_ORIGIN on the private bucket with content-type, and permit the application role to sign PUT and version-specific GET. The worker needs private object reads, version listing and version deletion for abandoned uploads. Keep noncurrent versions referenced by submitted briefs. Catalog media uses a different bucket and is served through the application's catalog route.

Run `npm run worker` every minute on a worker host with an up-to-date ClamAV database and clamscan on PATH. Supply the same database, storage and mail settings there. Enquiries and account recovery use SMTP_URL, MAIL_FROM, STUDIO_INBOX, APP_ORIGIN and a private RECOVERY_SECRET of at least 32 characters. Each invocation processes bounded batches. Failed items become eligible again after their lease expires. Alert on worker failures, pending items older than ten minutes, unresolved payments and rejected uploads. Review private design retention with the owner.

## Release rehearsal

Run the isolated suite on each change. Before launch, repeat both journeys on staging with an approved print, actual photos and a public GLB, Razorpay test credentials, versioned storage, scanning and a test inbox. Check model rotation on a physical phone, download authorization, emails, cancellation, refunds and dispatch updates. Restore a staging backup into a separate replica set and verify record counts, order totals and versioned media access. Restore and rollback procedures depend on the chosen hosting provider. Keep live credentials separate from staging.
